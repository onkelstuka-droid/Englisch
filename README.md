# Vokabelheft Englisch

Englisch lernen ohne Bilder: Vokabeln, Hören, Schreiben, Satzbau, Grammatik und Sprechen – mit Vorlesen, Wiederholungs-System und gespeichertem Fortschritt.

**App öffnen:** https://onkelstuka-droid.github.io/Englisch/

Auf dem Handy in Chrome öffnen → ⋮ → „Zum Startbildschirm hinzufügen“.
